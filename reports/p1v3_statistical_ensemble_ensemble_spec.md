# P1-v3 statistical ensemble specification

The primary ensemble has five method-level votes: Single-BOSS,
Bootstrap-BOSS, PC, MMPC and FGES. A bootstrap run is not a vote; the complete
Bootstrap-BOSS condition contributes one vote after its candidate-specific
aggregation. An edge is retained by the primary ensemble only with at least
three of five method votes. GFCI is reported separately as sensitivity-only.

All six Bootstrap-BOSS candidates are retained and reported. No candidate is
selected using development semantic results. Semantic evidence is collected
once from the shared union and then filtered and closed independently for each
parent condition.
